# 룩선 코디 자동화 MVP

## 실행
1. Python 3.10+ 설치
2. 이 폴더에서 `pip install -r requirements.txt`
3. `streamlit run app.py`
4. 브라우저에서 `http://localhost:8501` 열기

## 네이버 API 연결
- NAVER Cloud Platform > NAVER API HUB에서 **검색어 트렌드** 사용 신청 후 Client ID / Client Secret 발급.
- 앱 ① 탭에 키 입력. 키는 파일에 저장하지 않으며 Streamlit 세션에서 사용.
- 공식 API: `POST https://naverapihub.apigw.ntruss.com/search-trend/v1/search`.
- 입력한 후보 키워드의 모바일 검색 상대 추이를 조회. 검색량 절댓값, 인기 키워드 자동 발굴은 지원하지 않음.
- 요청마다 최대 5개 그룹, 동일 앵커 키워드 포함 4개 후보씩 비교. **서로 다른 배치의 지수끼리는 비교 불가**. 전주 대비 상승률로 정렬.

## 에이블리 상품 연결
- 에이블리 브랜드 전체 상품·실시간 판매 순위를 읽는 공개 API는 확인되지 않음.
- ② 탭에서 상품 JSON 입력 또는 업로드. `source`는 `에이블리 브랜드`로, `category`는 `아우터/상의/하의/신발/가방` 중 하나로 입력.
- `rank`는 **실제로 확인한** 순위만 사용. 미확인 시 9999. `warmth/lightness/softness`는 1~10 수동 평가값으로 객관적 측정치가 아님.
- 샘플은 **가상 상품**이며 실사용 코디 생성은 차단됨. 실상품 URL·가격·소재 확인 후 교체.

## 출력
- 실제 상품 5개 카테고리가 있어야 조합 가능.
- 전체 150,000원 이하, 보온성 목표 5/10, 혼합 스타일, 기본 3세트.
- 결과 상품 링크, 가격 합계, 블로그 마크다운 초안, JSON 다운로드.
- 게시 전 상품 재고/가격/소재/핏, 광고 표시 및 AI 이미지 표시를 검수할 것.

## 한계
- 에이블리 자동 수집/스크래핑 없음. 브랜드 순위는 검증된 수동 입력만 사용.
- 자동 이미지 생성/블로그 발행/예약 실행은 미구현.
- 키워드 후보 자체는 사용자가 입력해야 함.
